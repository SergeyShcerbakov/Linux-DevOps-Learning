# / - root
<details>
/ — root  

Корень всей файловой системы.  
Все остальные каталоги находятся внутри /.  
```
/
├── etc
├── home
├── var
├── usr
└── ...
```
</details>

# /etc — конфигурация
<details>
Системные конфигурационные файлы.  

Примеры:  

/etc/passwd  
/etc/hosts  
/etc/fstab  
/etc/ssh/  

➤ Настройки системы и служб  
</details>

# /var — изменяемые данные
<details>
Данные, которые постоянно изменяются во время работы системы.  

Например:  
```
/var/log/      # логи
/var/cache/    # кэш
/var/lib/      # данные приложений
```
➤ Логи, кэш, базы и другие рабочие данные.
</details>

# /home — домашние каталоги
<details>
Личные файлы пользователей.  

/home/neo  
/home/user1  
/home/user2  

➤ Файлы обычных пользователей.  
</details>

# /tmp — временные файлы
<details>
Временные файлы программ и пользователей.

➤ Обычно содержимое может автоматически очищаться.
</details>

# /usr — программы и системные ресурсы
<details>
Основная часть установленных программ, библиотек и документации.
```
/usr/bin/      # команды
/usr/sbin/     # системные команды
/usr/lib/      # библиотеки
/usr/share/    # документация, данные
```
➤ Программы и их ресурсы.
</details>

# /opt — дополнительное ПО
<details>
Место для дополнительного или стороннего программного обеспечения.  

Например:  

/opt/app/  
/opt/google/  

➤ Сторонние/дополнительные приложения.
</details>

# /dev — устройства
<details>
Специальные файлы, через которые Linux взаимодействует с устройствами.  

Например:  

/dev/sda  
/dev/nvme0n1  
/dev/null  

➤ Диски, терминалы и другие устройства представлены как файлы  
</details>

# /proc — информация о системе и процессах
<details>
Виртуальная файловая система с информацией о работающем ядре и процессах.  

/proc/cpuinfo  
/proc/meminfo  
/proc/1234/  

➤ Информация о процессах, CPU, RAM и ядре.  
</details>

# /sys — информация об устройствах и ядре
<details>
Виртуальная файловая система для взаимодействия с ядром и устройствами.  

/sys/class/  
/sys/devices/  
/sys/block/  

➤ Информация об устройствах и параметрах ядра.  
</details>

# /boot — загрузка Linux
<details>
Файлы, необходимые для загрузки системы.
```
/boot/vmlinuz...    # ядро
/boot/initrd...     # initial RAM filesystem
/boot/grub/         # GRUB
```
➤ Ядро Linux и файлы загрузчика.
</details>

# /root — домашний каталог root
<details>
Домашняя директория пользователя root.

/root

➤ Домашние файлы и настройки суперпользователя.
</details>

# /run — данные текущего запуска
<details>

Временные данные работающей системы: PID-файлы, socket-файлы и т. д.  

/run/  
/run/sshd/  
/run/systemd/  

➤ Runtime-информация текущей сессии/загрузки.  

Обычно находится в RAM и очищается после перезагрузки.  
</details>

# /mnt — временное монтирование
<details>
Точка для ручного монтирования файловых систем.

/mnt/disk  
/mnt/backup  

➤ Временное подключение дисков и файловых систем.
</details>

# /media — съёмные устройства
<details>
Автоматически подключаемые съёмные устройства.  

/media/user/USB  

➤ USB-флешки, внешние диски и другие съёмные носители.
</details>

# /srv — данные сервисов
<details>
Данные, которые предоставляет система через сетевые сервисы.

Например:  

/srv/www/  
/srv/ftp/  

➤ Данные, предоставляемые сервисами.
</details>

# /lib — системные библиотеки
<details>
Библиотеки, необходимые программам и системным утилитам.

➤ Системные библиотеки и загрузочные модули.

В современных системах /lib может быть symlink на /usr/lib.
</details>

# /bin — основные команды
<details>
Базовые команды, необходимые для работы системы.

/bin/sh  
/bin/ls  
/bin/cp  
/bin/mv  

➤ Основные пользовательские команды.

В современных Linux-дистрибутивах /bin часто является symlink на /usr/bin.
</details>

# /sbin — системные команды
<details>
Команды для администрирования системы.

/sbin/mount  
/sbin/fsck  

➤ Системные/административные команды.

В современных системах /sbin также часто является symlink на /usr/sbin.
</details>
