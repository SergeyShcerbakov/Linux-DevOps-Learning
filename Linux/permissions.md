# Important rule :
```
Права каталога - это что можно делать с объектом внутри.      Example: folder: rwx  
Права файла - это что можно делать с содержимым самого файла.          file:   r--  
```

# chmod

##Установка прав в числовом формате:  
- `chmod 775 file`- rwx rwx r-x 

##Установка прав в буквенном формате:  
- `chmod u+x file` - Дать владельцу право на выполнение  

- `chmod g-w file` - Убарть у группы право на запись  

- `chmod o+r file` - Дать остальным право на чтение  

# SUID, SGID, Stiky bit
```
SUID	   s→ u+s
SGID	   s→ g+s
Sticky bit t→ +t
```
```
4=SUID				4000=SUID		6000=SUID+SGID
2=SGID				2000=SGID
1=Sticky (t-bit)	1000=Sticky		7000=SUID+SGID+Sticky
0=ничего
```
Если нет execute (X)- буква становится заглавной  
- `s>S`
- `t>T`

#SUID (Set User ID) - специальный бит для файла  
Все новые файлы и папки внутри наследуют группу каталога,а не группу пользователя который их создал.  

При запуске файла с установленными правами SUID программа выполняется с правами владельца файла, а не пользователя который её запустил. SUID имеет смысл именно для исполняемых файлов. Для каталогов поведение SUID не используется как повышение прав.  

- `сhmod u+s file` - добавить специальный бит  
- `chmod 4775 file` - добавить специальный бит  
- `chmod 0775 file` - убрать специальный бит  

#SGID (Set Group ID)  
Применяется к исполняемым файлам и каталогам.  
Для исполняемого файла: запускается с группой владельца файла  
Для каталога:			новые файлы и каталоги внутри него наследуют группу родительского каталога.  

- `chmod g+s`  
- `chmod 2775`  
- `chmod 0775`  
```
chmod g+s /shared
и у shared группа:
root developers
То новые файлы внутри /shared будут наследовать группу developers, независимо от того какой пользователь их создал.
```
SGID на каталоге: новые файлы и каталоги созданые внутри него, наследуют группу этого каталога.  

#Sticky bit - t  
Применяется к каталогам.  
Пользователи могут создавать файлы в общем каталоге, но не могут удалить или переименовать чужие файлы в этом каталоге.  

- `chmod 1775 folder` - добавить специальный бит  
- `chmod 0775 folder`
