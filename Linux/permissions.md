# Important rule :
Права каталога - это что можно делать с объектом внутри.      Example: folder: rwx
Права файла - это что можно делать с содержимым самого файла.		   file:   r--

# chmod		
		rwx
		421
Установка прав в числовом формате:
chmod 775 file

Установка прав в буквенном формате:
chmod u+x file Дать владельцу право на выполнение
chmod g-w file Убарть у группы право на запись
chmod o+r file Дать остальным право на чтение
