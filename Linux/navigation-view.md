### Просмотр
<details>

ls -alh
```
-a   показывает все файлы, включая скрытые  
-l   предоставляет формат длинного списка с подробной информацией  
-h   делает размеры файлов человечески читаемыми виде  
```

</details>

### Сортиврока файлов
<details>

```
ls -lt   - эта команда содержит файлы в длинном формате (-l), отсортированные по времени изменения (-t), с последними измененными первыми.

ls -ltr  - параметр r меняет порядок сортировки. Повторяю: если время редактирования всех файлов совпадает, то не видно различий.

-R       - перечислять подкаталоги рекурсивно (отображает содержимое всех подкаталогов)
-S       - сортировать по размеру файла, самый крупный сначала
-X       - сортировать по расширению файла в алфавитном порядке
-v       - сортировать по версии (полезно для пронумерованных файлов)
```

</details>

### Просмoтр внутри каталогов
<details>


```
ls -l test   - просмотр каталога
ls -l */     - покажет содержимое всех ближайших подкаталогов в вашем текущем местоположении.Можете использовать символы для просмотра нескольких каталогов одновременно.
```
```
ls | cowsay       - весёлый трюк с коровой
```
```
ls --color=never  - отображение вывод без цветов

never: никогда не используйте цвета (то, что мы только что пробовали)
always: всегда использовать цвета, даже при отправке вывода в файл или другую команду
auto: используйте цвета при отправке вывода напрямую на терминал, но не при отправке вывода в другое место

Использование ls --color=never может быть полезно в сценариях или когда вы хотите обеспечить стабильный результат, независимо от настроек вашего терминала.
```

</details>

### pwd
<details>

```
pwd (print working directory) - показывает полный путь где мы сейчас находимся, текущее местоположение
pwd -L                        - используйте параметр -L для отображения логического пути
pwd -P                        - используйте опцию -P для отображения физического пути на диске
```
```
ls -l
total 0
drwxr-xr-x 2 labex labex 24 Oct 10 17:08 real_dir
lrwxrwxrwx 1 labex labex 28 Oct 10 17:08 symlink_dir -> /home/labex/project/real_dir

pwd -L
/home/labex/project/symlink_dir
pwd -P
/home/labex/project/real_dir

pwd и pwd -L сохраняют символическое имя ссылки в результате, а pwd -P решает ссылку и отображает фактическую папку.
```

</details>
