# /

/ — root  

Корень всей файловой системы.  
Все остальные каталоги находятся внутри /.  
```
/
├── etc
├── home
├── var
├── usr
└── ...
```
# /etc — конфигурация

Системные конфигурационные файлы.  

Примеры:  

/etc/passwd  
/etc/hosts  
/etc/fstab  
/etc/ssh/  

➤ Настройки системы и служб  

# /var — изменяемые данные

Данные, которые постоянно изменяются во время работы системы.  

Например:  
```
/var/log/      # логи
/var/cache/    # кэш
/var/lib/      # данные приложений
```
➤ Логи, кэш, базы и другие рабочие данные.

# /home — домашние каталоги

Личные файлы пользователей.  

/home/neo  
/home/user1  
/home/user2  

➤ Файлы обычных пользователей.  

# /tmp — временные файлы

Временные файлы программ и пользователей.

➤ Обычно содержимое может автоматически очищаться.

# /usr — программы и системные ресурсы

Основная часть установленных программ, библиотек и документации.
```
/usr/bin/      # команды
/usr/sbin/     # системные команды
/usr/lib/      # библиотеки
/usr/share/    # документация, данные
```
➤ Программы и их ресурсы.

# /opt — дополнительное ПО

Место для дополнительного или стороннего программного обеспечения.  

Например:  

/opt/app/  
/opt/google/  

➤ Сторонние/дополнительные приложения.

# /dev — устройства

Специальные файлы, через которые Linux взаимодействует с устройствами.  

Например:  

/dev/sda  
/dev/nvme0n1  
/dev/null  

➤ Диски, терминалы и другие устройства представлены как файлы  

# /proc — информация о системе и процессах

Виртуальная файловая система с информацией о работающем ядре и процессах.  

/proc/cpuinfo  
/proc/meminfo  
/proc/1234/  

➤ Информация о процессах, CPU, RAM и ядре.  

# /sys — информация об устройствах и ядре

Виртуальная файловая система для взаимодействия с ядром и устройствами.  

/sys/class/  
/sys/devices/  
/sys/block/  

➤ Информация об устройствах и параметрах ядра.  

# /boot — загрузка Linux

Файлы, необходимые для загрузки системы.
```
/boot/vmlinuz...    # ядро
/boot/initrd...     # initial RAM filesystem
/boot/grub/         # GRUB
``
➤ Ядро Linux и файлы загрузчика.

# /root — домашний каталог root

Домашняя директория пользователя root.

/root

➤ Домашние файлы и настройки суперпользователя.
