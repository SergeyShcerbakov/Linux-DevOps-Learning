### 1. Процесс (process) — это запущенный экземпляр программы.  
`Программа → запуск → Процесс`
<details>

Например: python app.py  
app.py — программа/файл, а запущенный python app.py — процесс.

Каждый процесс имеет свой PID (Process ID) — уникальный идентификатор процесса.

</details>

# 2. PID и PPID

<details>
PID (Process ID)— ID самого процесса.  

PPID (Parent Process ID) — индификатор родительского процесса.  

```
ps				  - посмотреть
ps aux			  - посмотреть конкретнее 
ps aux | grep vim - gпосмотреть и найти процесс vim
```
Правильно:
#Всё ниже — потомки (descendants) systemd.

```
А непосредственно под ним — его дочерние процессы.
systemd
   │
   ├── sshd          ← child systemd
   │    └── bash     ← child sshd
   │         └── vim ← child bash
   │
   └── nginx         ← child systemd
```

</details>

# 3. Основные команды
<details>

```
| Команда      | Что делает                                  |
| ------------ | ------------------------------------------- |
| ps           | показать процессы                           |
| ps aux       | показать все процессы                       |
| ps -ef       | процессы + PPID                             |
| top          | процессы в реальном времени                 |
| htop         | удобный интерактивный `top`                 |
| pgrep name   | найти PID по имени                          |
| pidof name   | найти PID программы                         |
| kill PID     | отправить сигнал процессу                   |
| pkill name   | отправить сигнал по имени                   |
| jobs         | процессы текущего shell                     |
| fg           | вернуть job на передний план                |
| bg           | запустить остановленный job в фоне          |
| nohup        | продолжить работу после выхода из терминала |
```

top показывает процессы динамически в реальном времени, а htop позволяет интерактивно работать с ними

</details>

# 4. ps

<details>

ps - текущие процессы

USER — владелец  
PID — ID процесса  
%CPU — использование CPU  
%MEM — использование RAM  
STAT — состояние  
COMMAND — команда  

</details>
