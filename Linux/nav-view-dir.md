# 2. Сортиврока файлов
<details>

```
ls -lt   - эта команда содержит файлы в длинном формате (-l), отсортированные по времени изменения (-t), с последними измененными первыми.

ls -ltr  - параметр r меняет порядок сортировки. Повторяю: если время редактирования всех файлов совпадает, то не видно различий.

-R       - перечислять подкаталоги рекурсивно (отображает содержимое всех подкаталогов)
-S       - сортировать по размеру файла, самый крупный сначала
-X       - сортировать по расширению файла в алфавитном порядке
-v       - сортировать по версии (полезно для пронумерованных файлов)
```

</details>

# 3. Просмoтр внутри каталогов
<details>


```
ls -l test   - просмотр каталога
ls -l */     - покажет содержимое всех ближайших подкаталогов в вашем текущем местоположении.Можете использовать символы для просмотра нескольких каталогов одновременно.
```
```
ls | cowsay       - весёлый трюк с коровой
```
```
ls --color=never  - отображение вывод без цветов

never: никогда не используйте цвета (то, что мы только что пробовали)
always: всегда использовать цвета, даже при отправке вывода в файл или другую команду
auto: используйте цвета при отправке вывода напрямую на терминал, но не при отправке вывода в другое место

Использование ls --color=never может быть полезно в сценариях или когда вы хотите обеспечить стабильный результат, независимо от настроек вашего терминала.
```

</details>

# 4. pwd
<details>

```
pwd (print working directory) - показывает полный путь где мы сейчас находимся, текущее местоположение
pwd -L                        - используйте параметр -L для отображения логического пути
pwd -P                        - используйте опцию -P для отображения физического пути на диске
```
```
ls -l
total 0
drwxr-xr-x 2 labex labex 24 Oct 10 17:08 real_dir
lrwxrwxrwx 1 labex labex 28 Oct 10 17:08 symlink_dir -> /home/labex/project/real_dir

pwd -L
/home/labex/project/symlink_dir
pwd -P
/home/labex/project/real_dir

pwd и pwd -L сохраняют символическое имя ссылки в результате, а pwd -P решает ссылку и отображает фактическую папку.
```

</details>

# 5. cd — Change Directory (сменить каталог)

<details>

```

```

</details>

# 6. mkdir

<details>

Создание каталога 'личный' с ограниченными полномочиями:  
`mkdir -m 700 ~/project/digital/privat `  

Чтобы проверить полномочия, воспользуйтесь:  
`ls -ld ~/project/digital/private `  

Создадние нескольких каталогов в подробном режиме:  
```
mkdir -v ~/project/digital/resources/book ~/project/digital/resources/articles ~/project/digital/resources/videos  

Параметр -v обозначает «разговорный». Он указывает mkdir распечатать сообщение для каждой созданной папки.
```

Создать вложенную структуру для гипотетического исследовательского проекта с ограниченными полномочиями:  
```
mkdir -pvm 750 ~/project/digital/projects/research/drafts ~/project/digital/projects/research/references

-p:     Создание родительских каталогов по мере необходимости
-v:     Подробный режим, печать сообщение для каждой созданной каталога
-m 750: Установить полномочия
```

Посмотреть дерево:  
`free ~/project/digital_garden`
Посмотреть дерево с правами:  
`tree -p ~/project/digital_garden`

Дополнительные параметры mkdir:

```
-Z: Установить стандартный тип контекста безопасности SELinux для каждой созданной каталога
--context[=CTX]: Как -Z, или если указан CTX, установите для контекста безопасности SELinux или SMACK CTX
--version: Выходные сведения и выход
```

</details>

# 7. mkdrir - Brace Expansion (раскрытие фигурные скобок)

<details>

**Brace Expansion** (раскрытие фигурных скобок) в Bash — создание множества имён файлов и каталогов с помощью шаблонов в фигурных скобках:  

```
mkdir {2010..2012}-0{1..9} {2010..2012}-{10..12}

mkdir -p playground/dir-{00{1..9},0{10..99},100}

touch playground/dir-{00{1..9},0{10..99},100}/file-{A..Z}


-p вынужнает mkdir создавать родителоьские каталоги c указанием пути
```
-p создаёт промежуточные каталоги автоматически:  
`mkdir -p a/b c/d`

Сразу две команды испльзовать разные:  
`mkdir dir1 && touch dir1/file.txt`

</details>
